# ⑥-2C-1 正式购买填写与前后台闭环

## 范围与基线

本阶段从 ⑥-2B 验收基线 `c3a96bd6038070050c98c94b58612cab68a95b0f` 开始，把既有冻结模板、加密草稿、私有图片、购买行、统一报价、订单资料快照和独立归档附件接入商城前后台。实现仍使用现有 Nuxt 4、Vue 3、Nuxt UI 4、Fastify、PostgreSQL 与 Kysely 模块化单体。

此阶段只完成本地购买资料填写和本地订单展示。顾客填写内容不会自动成为上游采购参数；`http_json_v1` 请求、摘要、历史操作及恢复协议不变。现有六种履约方式继续由原履约系统处理，人工履约订单项可以查看购买资料；自动履约 SKU 使用填写模板时，管理端会提示资料仍需人工处理。未接入卡易信自动采购，也不改变价格、付款、退款或对外供货阶段。

## 启用状态和有效配置

前向迁移 `202610250003_purchase_form_activation_state` 移除旧 `purchase_forms_enabled` 布尔列，以 `preparing`、`active`、`paused` 表示购买填写状态。旧 `false` 安全映射为 `preparing`；旧 `true` 保留当时已启用的有效关联。迁移不修改订单摘要、已售版本、库存和资金事件。

- `preparing` 不让后台准备关联影响商城的购买行为；顾客读取有效填写模板时不暴露准备关联。
- 管理员首次启用前可检查模板冻结版本、商品默认、SKU 覆盖、配置完整性和履约处理影响；确认时提交本次影响摘要。事务锁与影响摘要校验阻止确认期间配置变化。
- 首次启用将准备关联复制到独立的 `applied_*` 关联。此后只能 `active → paused → active`，状态转换由数据库触发器和管理 API 一起约束。
- 启用后编辑关联只改准备值；管理员执行“保存并应用”后才更新生效关联。应用请求校验商品修订和准备关联内容，旧确认不能应用新编辑。
- SKU 的已应用模板覆盖优先，其次使用商品已应用模板；SKU 的 `none` 显式关闭继承，`product_default` 才继承商品规则。有效关联指向冻结版本 UUID，改动不会重写已有订单快照。
- 有模板的 SKU 暂停时不可创建新订单，即使模板字段全选填也同样处理。无模板 SKU 仍按原购买流程成交。混合购买行一并校验；报价不能绕过下单时的状态复查。
- 已提交的幂等请求先恢复原订单，再检查当前暂停状态；暂停不撤销已成交订单、履约、付款、售后、草稿或附件。
- 降级迁移在状态或关联无法由旧布尔及单层关联表达时会在 DDL 前拒绝，避免回滚暂停状态而重新放开下单、或删除准备状态。

## 草稿、附件和购买行

顾客接口只按 SKU 当前有效模板工作：读取有效模板、创建草稿、读写本人草稿、显式校验、删草稿，以及上传、查看、删除私有图片。顾客和游客 owner 由服务端会话 / 游客 cookie 推导，客户端不能指定 owner 或冻结版本。游客资料仅在登录后由原 ⑥-2B 购物车认领事务按本次指定草稿迁移归属，不扫描历史游客草稿。

草稿沿用 ⑥-2A 密文、独立 AAD、密钥环、修订冲突、限额、到期和清理约束。图片替换先校验并持久化新图，再由草稿更新及原附件删除保护协调提交；旧图容量满时仍可安全替换。更新失败时原资料和图片保留。订单成功时，成交冻结资料快照和图片归档在原订单事务中独立保存，草稿修改、过期、删除与清理不删除订单归档。

购买行继续以服务端计算的 SKU、冻结版本、规范化内容组成身份。相同 SKU 和相同规范内容合并；不同账号、选项、区服或图片维持分行。草稿、购买行、报价、订单创建继续共用 ⑥-2B v2、修订号和幂等恢复，不建立第二套购物车或订单。立即购买直接报价与成交，无需先加入购物车。编辑行时只改目标行；服务端合并时返回保留的 `lineId`；编辑失败不删除原行。

模板改版、草稿到期或修订冲突时，商品页重新取得当前 SKU 的有效模板及草稿；旧模板资料不会被静默用来成交，顾客需要在当前冻结版本下重新确认。切换 SKU 会重置字段、校验和进行中的异步状态，过期响应不能覆盖当前 SKU。填写正文不进入 URL、`sessionStorage` 或 `localStorage`。

## 订单资料的授权查看

- 顾客订单详情按订单项显示成交快照字段、成交时名称和值及对应图片。
- 游客订单沿用订单会话归属；不能通过订单 ID 猜测访问。
- 管理订单详情逐订单项展示快照和经授权读取的图片；购买资料为只读成交证据。
- 图片响应每次经过对应顾客、游客或管理员的身份及订单项授权检查，采用私有缓存、安全内容类型与响应头；不暴露存储路径、永久公网 URL 或第三方下载链接。
- 正常访问只返回授权展示所需资料，不返回数据库内部对象、密钥元数据或物理路径。含正文的草稿写入 / 校验路由采用静默请求日志；全局请求体日志也做脱敏。
