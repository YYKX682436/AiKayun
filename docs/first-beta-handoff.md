## 授权

授权中心是独立项目 [AiKayun-License](https://github.com/YYKX682436/AiKayun-License)，仓库保持 Private；生产服务位于原 MyShop 服务器的 `/data/aikayun-license`，使用独立数据库。公网入口预计为 <https://license.aiove.top>，目前尚未接入商城的 HTTPS 服务。

本次许可证已创建，状态为 **active、尚未激活**，到期时间为 **2026-12-11 13:40（北京时间）**。激活码保存在服务器受保护位置，商城安装后由 Codex 通过正常流程使用。授权中心目前没有管理网页；创建、发码、续期、停用和恢复使用服务器上的现有受控管理工具，店主可向 Codex 提出具体操作，不需要自己学习命令行。

离线根私钥只在本机 `~/.config/aikayun-production`，没有上传到服务器或仓库。备份时，在 Finder 的“前往 → 前往文件夹”输入 `~/.config/aikayun-production`，将整个目录复制到你自己的**加密 U 盘或加密磁盘映像**，然后卸载并与电脑分开保管。如果没有加密介质，可在 Mac“磁盘工具”选择“文件 → 新建映像 → 空白映像”，选择加密并自行设置密码，打开映像后复制该目录，再推出映像并把映像文件放到 U 盘。备份密码请自行保管，不要把备份、密码或密钥发给内测用户。

## 内测使用

商城安装和激活后，在后台商品页面创建明确标注“内测专用”的零元商品，只使用没有实际价值的测试内容。用户从商城注册并下单，在订单页面查询交付。本轮没有配置支付商户，真实支付、充值和退款未验证。

给内测用户的说明，需在实际下单和交付验证通过后再发送：

> 请打开 <https://aikayun.aiove.top> 注册账号，选择标注“内测专用”的零元商品并下单，再在订单页面查看测试交付内容。本次商品没有实际价值，不需要付款。遇到问题请把页面和操作步骤反馈给店主。

## 维护信息

- 商城仓库为 Public，授权中心仓库和四个 GHCR 暂存包保持 Private。
- 内测服务器可通过本机 `ssh myshop-prod` 连接；商城安装目标为 `/opt/aikayun`。更多连接说明在本机 `AGENTS.md`。
- 发行由商城仓库的 [Commercial release](https://github.com/YYKX682436/AiKayun/actions/workflows/release.yml) 手动工作流完成。选择 `main`，填写未使用过的版本号，确认文字填写 `PUBLISH-` 加同一个版本号。流程会检查维护者身份、同一提交的 CI、真实授权信任、双架构镜像扫描与签名；已使用过的版本号不能重复使用。
- PostgreSQL 使用基于固定官方镜像的针对性修补版本，已升级 `libxslt` 并清除 CVE-2026-125350 等三项相关告警；每个架构仍有 42 项此前评估过的 HIGH/CRITICAL，其中 26 项在启动辅助程序的 Go 标准库，16 项在 Kerberos 库。数据库不对公网开放，本轮不使用 Kerberos 或 SQL XML 扩展。Caddy 官方镜像每个架构有 2 项 HIGH：CVE-2026-116587 的 go-jose/v3 暂无补丁，CVE-2026-78661 上游已有补丁但当前官方镜像尚未包含；现有配置只进行反向代理，不将客户请求交给这些受影响的解析功能。扫描未关闭，只对经过具体评估的固定镜像和报告接受有限风险；镜像、告警或部署方式变化时会重新阻断。备份镜像的依赖已更新，两个架构当前扫描均无 HIGH/CRITICAL 或秘密告警。
- 授权管理网页尚未开发，后续只计划提供许可证列表、创建授权、发码、续期、停用和恢复。
