## 授权

授权中心是独立项目 [AiKayun-License](https://github.com/YYKX682436/AiKayun-License)，仓库保持 Private；生产服务位于原 MyShop 服务器的 `/data/aikayun-license`，使用独立数据库。商城通过 <https://license.aiove.top> 连接授权服务，该地址是服务接口，不是管理网页。

本次测试许可证已激活，许可证到期时间为 **2026-12-11 13:40（北京时间）**。后台可能显示更早的短期授权凭证有效期；系统会尝试自动续期，但本次尚未等待到实际自动续期发生。授权中心目前没有管理网页；创建、发码、续期、停用和恢复使用服务器上的现有受控管理工具，店主可向 Codex 提出具体操作，不需要自己学习命令行。

离线根私钥只在本机 `~/.config/aikayun-production`，没有上传到服务器或仓库。备份时，在 Finder 的“前往 → 前往文件夹”输入 `~/.config/aikayun-production`，将整个目录复制到你自己的**加密 U 盘或加密磁盘映像**，然后卸载并与电脑分开保管。如果没有加密介质，可在 Mac“磁盘工具”选择“文件 → 新建映像 → 空白映像”，选择加密并自行设置密码，打开映像后复制该目录，再推出映像并把映像文件放到 U 盘。备份密码请自行保管，不要把备份、密码或密钥发给内测用户。

## 维护信息

- 商城仓库为 Public，授权中心仓库和四个 GHCR 暂存包保持 Private。
- 内测服务器可通过本机 `ssh myshop-prod` 连接；商城已安装在 `/opt/aikayun`，当前正式签名发行版本为 `0.1.0-rc.14`。更多连接说明在本机 `AGENTS.md`。
- 发行由商城仓库的 [Commercial release](https://github.com/YYKX682436/AiKayun/actions/workflows/release.yml) 手动工作流完成。先让 Codex 复用已有签名身份，为新版本准备对应的授权信任配置；然后用维护者账号点击“Run workflow”，选择 `main`，填写未使用过的版本号，确认文字填写 `PUBLISH-` 加同一个版本号。流程会检查维护者身份、同一提交的 CI、真实授权信任、双架构镜像扫描与签名；已使用过的版本号不能重复使用。
- PostgreSQL 使用基于固定官方镜像的针对性修补版本，已升级 `libxslt` 并清除 CVE-2026-125350 等三项相关告警；每个架构仍有 42 项此前评估过的 HIGH/CRITICAL，其中 26 项在启动辅助程序的 Go 标准库，16 项在 Kerberos 库。扫描报告为这 42 项均列出了修复版本，但当前发行镜像仍包含旧组件，并非已经修复。数据库不对公网开放，本轮不使用 Kerberos 或 SQL XML 扩展。Caddy 官方镜像每个架构有 2 项 HIGH：CVE-2026-116587 的 go-jose/v3 暂无补丁，CVE-2026-78661 上游已有补丁但当前官方镜像尚未包含；现有商城和授权中心入口只进行反向代理，不将客户请求交给这些受影响的解析功能。扫描未关闭，只对经过具体评估的固定镜像和报告接受有限风险；发行源码中的镜像、报告或受控配置改变时会重新阻断，之后若调整服务器入口或插件也需重新评估。备份镜像的依赖已更新，两个架构当前扫描均无 HIGH/CRITICAL 或秘密告警。
- 上述两种镜像、两种架构对应的脱敏扫描报告保存在本机 `~/.config/aikayun-production/reviewed-scan-reports/`，已与发行门禁中的固定摘要核对。
- 授权中心数据库在镜像更新前已备份；商城的自动数据备份尚未配置，进入正式经营前需要补齐。
- 授权中心与 Caddy 之间使用的内部 TLS 证书有效至 2027-02-09 13:37（北京时间）；到期前由维护人员同时更新证书、密钥及 Caddy 的信任文件。
- 授权管理网页尚未开发，后续只计划提供许可证列表、创建授权、发码、续期、停用和恢复。
