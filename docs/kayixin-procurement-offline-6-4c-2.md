# ⑥-4C-2：卡易信 V3 离线协议及采购内核边界

固定基线 `4acf101ca244025078aa9b2bf724732857fee688`；⑥-4C-1 报告先以 `787f93b` 归档。本轮按新顺序开展隔离开发，没有访问真实采购或退款接口，也没有部署或触碰生产数据。⑥-4A 的官方协议历史记录与⑥-4C-1 的证据分级继续适用；目标商户与协议行为均为 **NOT_VERIFIED**。

## 实现及边界

- 沿用既有供应商连接配置、HTTPS 站点根、AppID、加密 AppSecret 和不可变配置/凭据版本，不为特定域名设置规则。测试专用解析器从冻结版本读取并检查协议、认证方式、连接、凭据版本和密钥 ID；测试组合器把该次解析结果绑定到同一次内核 pass。生产连接管理及只读调用保持原样。
- 生产共享代码保留无网络 I/O 的 detail 身份解析；合成 create 编码已移入测试目录。create 编码的类型和长度限制是夹具规则，不代表真实商户的 goodsId、SKU、金额、资料或数量语义已确认。隔离 HTTP 夹具验证文档中 create 路径、请求头和精确 UTF-8 字节签名；内核的 submit 仍阻断，不发送采购请求。
- 测试专用传输按冻结的合成身份查 detail，使用原始 outerNumber 或已知 orderNumber；只有两种身份回显一致时记录供应商号。状态、金额、卡密和成功码不解释为完成、扣费或交付。身份回显冲突以无上游号的冲突事实转人工，保留原身份和风险；无法解析或负查保持未知。既有内核继续执行单次意图、原身份恢复、预算、付款/退款、撞号和逐单位交付门禁。
- **尚未形成生产可用的采购适配器**：传输、冻结来源组合器只存在测试目录；生产没有采购传输或调度器，也没有真实数量/金额/状态解释或真实采购资格。当前工作为协议及内核接入的离线基础，不构成未来客户已能配置并使用自动采购的承诺。

币种及手续费、数量换算、safePrice 服务端扣费约束、outerNumber 去重及负查一致性、图片与资料编码、状态和退款含义、跨凭据查旧单均为 **NOT_VERIFIED**。未知结果不重购，参考报价不充当扣费上限。普通配置和直接 SQL 不得开启卡易信真实采购、退款或自动采购资格；原生产来源选择器和数据库门禁保持不变。

## 验证

合成协议夹具、真实 PostgreSQL 测试及全量验证结果以最终交付和对应 CI 记录为准。隔离夹具不能证明真实商户接单、扣费、退款、幂等或可交付性。生产备份恢复和真实商户行为未验证。


## ⑥-4C-2B：成交资料的内部准备

`prepareOrderItemProcurement` 以订单项 UUID 读取成交快照，使用该订单项冻结的审核映射、模板、供应商配置和凭据版本，不读取当前草稿或最新映射头。它复核商品/SKU、连接与凭据归属、模板/规则/上游结构摘要、成交内容身份，并复用现有购买资料规范化和供应商映射校验器。内部结果保留字段和选项 UUID、上游路径、选项原始值、数字字符串和文本空格；条件扩展按实际选择的分支关联。图片只带私有归档对象身份、摘要和大小，不读取或输出图片字节。此结果包含顾客资料，仅供受控内部调用，不提供 HTTP 路由，不写日志或审计。

内部准备结果和采购资格分离：付款资格使用原事务内订单锁检查，真实采购始终为 false，明确列出币种、最大扣费、手续费、数量换算、safePrice、outerNumber 和协议编码阻断；有图片或级联/扩展时另列对应编码阻断。不生成正式下单参数、不分配采购身份、不使用销售价、成本价或参考报价作为预算。生产来源选择器、TST 隔离预算及只读限制保持不变。

测试基于合成来源与真实 PostgreSQL/Fastify 订单，不证明商户行为。实际币种、数量、扣费、资料和图片编码、状态、去重、轮换后查单仍为 **NOT_VERIFIED**；未来真实协议须取得适用于商户的证据并另行验证。
