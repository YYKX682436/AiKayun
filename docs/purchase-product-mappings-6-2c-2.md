# ⑥-2C-2 供应商商品与购买字段对应准备

## 范围和边界

本阶段为本地商品/SKU、已应用的冻结购买模板和卡易信 V3 上游商品/SKU 建立带版本的准备映射。映射用于人工检查结构对应，不代表采购资格，也不创建可发送给上游购买接口的正式请求。

本阶段只使用卡易信现有的商品列表和商品详情只读操作。没有调用购买、查单、退款、图片上传接口；没有导入目录、自动铺货、同步本店售价或库存，也没有改变订单、履约、资金、退款或 `http_json_v1` 状态机。卡易信连接继续是 `fulfillmentEligible=false`，详情的 `procurementReady=false`。数据库协议保护仍拒绝卡易信自动履约连接。

## 身份和版本数据

迁移 `202610260001_supplier_product_mappings` 新增四类记录：

- `supplier_product_mapping_observations`：管理员发起的一次只读商品/SKU观察，包含连接及不可变配置版本、上游身份、字段结构快照、结构指纹、观察时间和30分钟有效期。观察绑定管理员，不写入购买资料。
- `supplier_product_mapping_heads`：本地 `product_id + product_variant_id` 唯一对应一个可编辑映射头；绑定卡易信连接/配置版本、上游商品和SKU身份、本地冻结模板版本、规范化版本及规则摘要。状态为 `draft`、`reviewed`、`stale`。
- `supplier_product_mapping_versions`：每次审核通过时追加的完整不可变审核快照，包括审核管理员和时间、配置版本、模板版本/摘要、规范化版本、字段规则/摘要、上游身份和字段树快照。
- `supplier_product_mapping_audit_events`：记录创建、草稿修改、审核、失效和恢复操作；摘要只记录版本、指纹和问题码，不写入供应商密钥或顾客正文。

本地身份使用不可变 `productId`、`skuId`，不使用名称。上游身份使用供应商连接ID、上游配置版本ID、`goodsId`、`skuType` 和 SKU 编码；有规格时另保存结构化规格组合。`skuType=0` 必须为无 SKU 编码且组合为空；`skuType=1/2` 必须有唯一 SKU 编码及非空规格组合。未知类型、缺失/重复编码、规格组合缺失或不一致均拒绝观察或审核。商品名只供人工阅读，不作为匹配键。

映射头通过本地 SKU 复合外键级联删除；审核版本和审计历史不依赖本地商品/SKU外键，所以符合现有安全删除规则的商品退役/删除不会被准备映射阻断，已审核记录也不会随头记录删除。供应商配置版本和冻结模板版本保留限制性引用，以免历史快照丢失其来源。

## 字段和选项对应

V3读取模型支持上游类型：`0` 文本、`13` 数字字符、`15` 多行文本、`14` 单选、`16` 级联（含 `children` 和 `expand`）、`1` 图片。本地规则用冻结模板的字段UUID与 `meaningKey` 定位，不用可改标签定位；选项也用冻结选项UUID与 `meaningKey`。上游没有稳定UUID，所以规则保存由字段、选项、子选项和扩展字段索引组成的有界结构路径，并同时保存完整规范化字段树快照及SHA-256指纹。数组路径只有在当前同一结构指纹下才有效，不单独充当身份。

服务端审核重新解析每个路径，并验证类型兼容、所有本地字段及本地选择项唯一对应、上游必填来源覆盖、级联父子层级、`expand`条件分支、重复字段/选项原始value和路径有效性。重复同名字段会给出可审查告警；完全相同的字段结构、重复选项value、未知字段类型、缺失/未知必填语义、不完整必填字段和无法唯一定位的选择项阻止审核。草稿可以保留未完成项，但不能绕过审核校验。

数字字符值按字符串保存，合成预览保留前导零；文本空格及大小写不做自动清理。图片仅对应本地受控附件对象引用，不生成供应商图片字段内容。图片数量、MIME/文件类型限制、二进制或URL编码及上游图片格式要求目前都没有真实商户证据。

上游 `regex`、HTML、JavaScript及表达式只作为未信任观察数据保存在结构快照里；校验和安全预览不会运行或解释它们。页面仅展示表达式存在状态，不提供脚本/转换编辑器。

## 结构摘要、审核和漂移

规范化上游结构指纹纳入结构版本、`goodsId`、商品类型/状态、`skuType`、SKU编码/规格组合以及完整购买字段、选项、子选项和 `expand` 树（含标题、规范化required语义及未知状态、placeholder和regex文本）。它不纳入商品展示名、报价、账户余额、库存或观察时间。重新命名商品不会单独使结构指纹变化；SKU身份编码、规格组合、商品结构/状态、字段树或供应商配置版本发生变化会要求重新审核。

本地来源检查记录冻结模板版本ID、模板内容SHA-256及规范化版本。当前已应用模板或规范化版本不同会显示为 `stale` 并阻止沿用旧规则。供应商凭据轮换/连接配置版本变化也会失效，即使地址或凭据看起来相同。只读重读后，结构/身份/配置/模板无变化时保留已审核版本；出现关键变化时，旧审核版本保留在历史中，当前头进入 `stale`。管理员修订草稿并重新审核会新增版本；恢复历史只能创建新草稿，不能覆盖原版本。

保存、审核和刷新使用产品→SKU→供应商连接→冻结模板→映射头的锁序，并以期望修订号执行乐观并发校验。审核历史和审计事件由数据库触发器禁止 UPDATE/DELETE/TRUNCATE；数据库也限制初始状态、修订递增、身份不变、合法状态转换及审核版本与头快照一致。`reviewed`、`stale` 仅表示映射审查状态，不会开启供应商自动履约。

## 后台和安全预览

管理入口为 `/admin/supplier-product-mappings`，仅使用管理员会话和CSRF保护的管理端点。它允许选择本地 SKU 和现有 V3 只读连接、读取商品列表/详情、选择明确上游 SKU、编辑字段和选项路径、检查问题、运行合成预览、保存草稿、审核、重读、查看历史及恢复为新草稿。页面标明已应用的本地模板版本、当前上游配置和字段结构观察版本；退役 SKU 不接受新编辑。

预览器是 contracts 内纯本地确定性函数，默认构造合成输入，只输出 `internal_mapping_preview` 中间表示、规则结果和图片来源对象引用。它不读顾客订单、已成交密文或真实采购金额，不输出协议购买载荷，不计算 `safePrice`/数量，不推断 `outerNumber` 去重语义，也不执行供应商表达式。管理员鉴权阻止顾客、游客访问；服务端重新读取上游结构并计算指纹，不信任浏览器提交的摘要。

服务端只接受连接ID和数字商品ID，使用现有固定V3详情读取器。浏览器不能传入任意 URL、HTTP 方法、路径或payload。凭据仍由既有加密存储处理，公开响应和审计不返回Secret。所有写入口均需管理员身份及CSRF。供应商列表、详情、余额接口仍不具备采购能力。

## 可供下一阶段使用的内容

下一阶段可以把一个 `reviewed` 映射版本作为本地字段语义、上游商品/SKU身份、配置来源及结构指纹的人工审核依据，并可用同一合成预览器检查纯内部的映射结果。必须重新读取当前上游详情并重验配置、商品/SKU身份、字段结构和本地模板版本。

这些数据不能直接发送给真实购买接口，也不构成购买载荷规范、图片编码规范、扣费规则、数量单位或去重保证。若下一阶段需要真实采购实现，必须另外获取并验证真实商户/站点字段语义、配置确认和请求编码，再按单独阶段授权实现。本阶段未进入⑥-3或⑥-4。

## 精准 R1：分支唯一性与异步归属

本次从固定基线 `537614979164382d4f7b5c55f774d15ac69a6e4a` 开始；开始时 `HEAD`、`origin/main` 和 GitHub `main` 一致，工作区干净。只修改既有规则校验、管理页请求归属和回归测试，没有新增迁移，也没有改写映射头、审核历史、只读供应商访问或采购资格模型。

### 修复内容

- 条件分支校验现在独立于上游 `required`。本地字段属于顶层还是某个级联选项的扩展分支，会与上游完整结构路径对应比较；顶层字段不能指向扩展字段，本地扩展字段不能指向顶层字段或其他选项分支。未知required语义仍由原有阻断保留。
- 对解析成功的完整上游字段路径和完整选项路径分别检查复用。不同本地字段不能复用一个上游字段身份；同一字段/父路径作用域下，不同本地选项不能复用一个上游选项身份。身份由当前观察结构中的路径确定，不比较标题、原始value相似度或数组显示顺序。父路径不同的选项即使原始value相同仍可分别映射。
- 合同预览沿用同一校验器，所以重复目标会出现在合成预览的阻断问题中。服务端草稿和审核也使用该校验器；审核接口回归确认错误映射不会追加审核版本。
- 后台每个读取、保存、刷新、审核、历史和恢复操作都捕获请求代际及当时的商品/SKU、连接配置、映射ID/修订、模板与观察身份。响应只在当前编辑区仍属于该请求时更新；保存结果可按自身身份更新该SKU摘要。操作token使旧请求的`finally`不能清除新操作状态；映射列表摘要和编辑区映射都拒绝较低修订回退。切换本地SKU会清空旧上游目录和详情。
